# نمونه تعاملی کافی‌نت

اجرای محلی با Node.js 18 یا جدیدتر، بدون نصب وابستگی:

```powershell
cd D:\Projects\Marketing-Lead\prototype
npm start
```

سپس نشانی `http://127.0.0.1:4173` را در مرورگر باز کنید. برای تغییر پورت می‌توان `PORT` را تنظیم کرد. آزمون‌های محاسبه با `npm test` و بررسی نحوی با `npm run check` اجرا می‌شوند.

این نسخه یک نمونه مستقل HTML/CSS/JavaScript است؛ انتخاب Vue و کتابخانه‌های نهایی به بررسی محیط و وابستگی‌ها موکول شده است. هیچ سرویس واقعی احراز هویت، ثبت دفتر، تراکنش، تحلیل یا API در آن متصل نیست. داده مثال فقط به‌صورت محلی نگهداری می‌شود، با دکمه شروع مجدد پاک می‌شود و پس از ۲۴ ساعت هنگام بازگشت منقضی می‌شود. برای تست دستگاه‌های دیگر باید سرور متناسب با محیط امن تنظیم شود؛ سرور پیش‌فرض فقط روی همان رایانه در دسترس است.
