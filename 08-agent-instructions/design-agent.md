## مشخصات
وایرفریم تمام استوری‌های کافی‌نت را در 360×640 و desktop بساز؛ برای هر استوری عنوان، interaction، حالت error/empty، CTA و artifact را نشان بده. طراحی بر اساس theme و semantic tokens؛ نسخه‌های رنگی هنوز Proposed و نیازمند contrast check. از تغییر UX مشترک برای یک صنف خودداری.

## معیارهای پذیرش این سند
- قواعد قابل اجرا، قابل آزمون و برای همه تمپلیت‌ها سازگار باشند.
- ادعای قابلیت موجود از پیشنهاد توسعه یا داده نمایشی تفکیک شود.
- RTL، واحد پول، حریم خصوصی و دسترس‌پذیری در خروجی رعایت شوند.
