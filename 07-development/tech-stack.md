## مشخصات
استک پیشنهادی برای پروژه مستقل: Vue3+TS+Tailwind+shadcn-vue+Unovis. این وابستگی‌ها در PRD حسابرو به‌عنوان وجود قطعی ذکر نشده‌اند. پیش از نصب نسخه‌ها، RTL، namespace CSS و لایبرری مورد نیاز پروژه مستقل را بررسی کن. منطق مالی pure function و عملیات حقیقی پشت Adapter.

## معیارهای پذیرش این سند
- قواعد قابل اجرا، قابل آزمون و برای همه تمپلیت‌ها سازگار باشند.
- ادعای قابلیت موجود از پیشنهاد توسعه یا داده نمایشی تفکیک شود.
- RTL، واحد پول، حریم خصوصی و دسترس‌پذیری در خروجی رعایت شوند.
