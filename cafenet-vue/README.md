# نمونه کافی‌نت با shadcn-vue

برای اجرا در این پوشه `npm install` و سپس `npm run dev` را اجرا کنید. آدرس محلی در خروجی Vite نمایش داده می‌شود. ساخت: `npm run build`؛ آزمون محاسبات با Node 22: `node --experimental-strip-types --test tests/*.test.mjs`.

نمونه برای بررسی UX است. اتصال واقعی، ثبت دفتر، تراکنش، احراز هویت و Analytics ندارد. داده نمونه به مدت حداکثر ۲۴ ساعت به صورت محلی باقی می‌ماند. فونت IRANYekanXVF فقط در صورت موجود بودن و داشتن مجوز استفاده می‌شود و فونت جایگزین سیستم در نظر گرفته شده است.
